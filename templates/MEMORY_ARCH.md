# MEMORY_ARCH

Settings that belong to this agent only. Everything shared by all agents lives in the spec copy at `memory/spec/`; do not repeat it here.

## Owner

| Field | Value |
|---|---|
| Agent | {agent} |
| User | {user} |

## Tags

One tag per row: what kind of question routes here. Semantic files may only use these tags.

| Tag | Questions that route here |
|---|---|
| agent | The agent itself: its memory system, tools, runtime environment |

## Error sources

Names allowed in an episodic's `Errors caught by` field. Must match `SOURCES` in `memory/tools/tally.py` character for character.

| Source | Meaning |
|---|---|
| user | The user caught it |
| tool | A tool caught it (e.g. `memory_check.py` output) |
| self | The agent caught it itself |
| subagent | A subagent caught it |
